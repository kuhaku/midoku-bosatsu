# 未読菩薩 (Midoku Bosatsu)

複数のあやしいわーるど系掲示板を1画面に表示するアプリです。

## 特徴

- 設定ファイルで取得対象の掲示板を増減可能
- 自動未読リロード機能
- サムネイル画像表示
- NGワード機能
- ハイライト機能
- レス通知機能
- キーボードだけでもある程度操作できる
- ツリー表示対応
- 省メモリ設計
